## 1. Git Repository

This folder is connected to the GitHub repository **Mission-MMA-Website**. Whenever changes are made to any file in this project, update the corresponding files in the repo to keep them in sync.

---

## 2. Lessons Learned

**Before planning or taking any action**, read every file in `docs/lessons/` and apply the guidance found there. Use `ls docs/lessons/` then read each file. Do not skip this step.

After making any correction to the code — bug fix, logic change, structural fix, or any non-trivial edit — create a new markdown file documenting the lesson learned. Save it to a `docs/lessons/` folder using the naming convention `YYYY-MM-DD-short-description.md`.

Each lessons file should include:
- What the problem was
- What the fix was
- Why it happened
- What to watch for in the future
